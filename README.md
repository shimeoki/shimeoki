# info

i mainly develop things in go. i also use nix (not advanced though) on a regular
basis and i am able to make web projects. i don't use ai/llm's to write code or
documentation for my stuff.

my new projects and repositories not required on github are located on
[codeberg](https://codeberg.org/shimeoki). github account mostly has archived
projects which were related to university or studying purposes.

## projects

these are some of my active projects. they are pretty simple yet not very
mature, counterintuitively. contains codeberg links.

- [obsidian-store](https://github.com/shimeoki/obsidian-store) - a vault
  organization plugin for [obsidian](https://obsidian.md)
- [kdly](https://codeberg.org/shimeoki/kdly) - a go library for
  [kdl v2](https://kdl.dev)
  - [kdlf](https://codeberg.org/shimeoki/kdlf) - a formatter using kdly
  - [kdlc](https://codeberg.org/shimeoki/kdlc) - a compressor using kdly
- [line](https://codeberg.org/shimeoki/line) - a go library for canonical line
  logging
- [nix32](https://codeberg.org/shimeoki/nix32) - a go library for base32
  encoding used in nix
- [system](https://codeberg.org/shimeoki/system) - my current nixos system
  configuration
